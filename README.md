# TFLint Ruleset Idiomatic

![GitHub Release (latest SemVer)](https://img.shields.io/github/v/release/terr4m/tflint-ruleset-idiomatic?logo=github&label=Release&sort=semver)
![Release](https://github.com/terr4m/tflint-ruleset-idiomatic/actions/workflows/release.yaml/badge.svg)
![Validate](https://github.com/terr4m/tflint-ruleset-idiomatic/actions/workflows/validate.yaml/badge.svg?branch=main)

A [TFLint](https://github.com/terraform-linters/tflint) plugin that enforces an idiomatic, consistent layout for Terraform configuration: where well-known attributes and blocks go, and how attributes and object keys are sorted.

## Documentation

Installation, usage and the full list of rules are in the [documentation](https://terr4m.github.io/tflint-ruleset-idiomatic/).

## Development

Requires Go, [just](https://github.com/casey/just) and [golangci-lint](https://golangci-lint.run/). Run `just` to list the available recipes.
